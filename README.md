# ARIMA Stock Price Analysis

## 📌 Project Overview

This project performs time series analysis and short-term stock price forecasting using the ARIMA (AutoRegressive Integrated Moving Average) model.

The analysis focuses on the historical closing prices of **Attock Petroleum Limited (APL)** using data obtained from Yahoo Finance.

## 🎯 Objectives

* Analyze historical stock closing prices.
* Examine the stationarity of the time series.
* Apply first-order differencing to achieve stationarity.
* Analyze autocorrelation using ACF and PACF plots.
* Build an ARIMA(1,1,1) model.
* Generate a five-period forecast of future closing prices.

## 📊 Dataset

**Company:** Attock Petroleum Limited (APL)
**Yahoo Finance Ticker:** `APL.KA`
**Data Period:** December 10, 2014 to December 10, 2024
**Main Variable:** Closing Price

The historical stock price data was downloaded using the `yfinance` Python library.

## 🔍 Analysis Performed

### 1. Data Collection and Preparation

Historical APL stock price data was downloaded from Yahoo Finance. The closing price series was extracted, converted to a proper time-series format, and checked for missing values.

### 2. Historical Price Analysis

The historical closing prices were visualized to observe the overall movement and patterns in APL's stock price over time.

### 3. Stationarity Testing

The **Augmented Dickey-Fuller (ADF) test** was applied to determine whether the original closing-price series was stationary.

Since stock prices are generally non-stationary, first-order differencing was applied.

### 4. Differencing

First-order differencing was performed to transform the original price series into a stationary series.

The ADF test was then applied again to the differenced data to check stationarity.

### 5. ACF and PACF Analysis

Autocorrelation Function (ACF) and Partial Autocorrelation Function (PACF) plots were used to examine the autocorrelation structure of the differenced series.

### 6. ARIMA Model

An **ARIMA(1,1,1)** model was fitted to the historical closing-price data.

The model was then used to generate a forecast for the next five trading periods.

### 7. Forecast Visualization

The historical closing prices and forecasted prices were plotted together to visually compare the observed historical data with the short-term ARIMA forecast.

## 📌 Conclusion

This project analyzed the historical stock prices of Attock Petroleum Limited using exploratory and time-series analysis techniques. The Augmented Dickey-Fuller test was used to check for stationarity, followed by first-order differencing. ACF and PACF plots were then used to examine the autocorrelation structure of the series.

An ARIMA(1,1,1) model was fitted to the historical closing prices and used to generate a five-period forecast. The results provide a short-term estimate based on historical price patterns.

However, stock prices are affected by many external factors, so the forecast should not be considered a guaranteed prediction of future prices.
